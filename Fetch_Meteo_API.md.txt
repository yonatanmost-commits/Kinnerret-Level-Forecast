# `isr_cities_1week_6hr_forecast.xml` — Full Technical Reference

---

## 1. File Access

**Direct URL (no authentication required):**
```
https://ims.gov.il/sites/default/files/ims_data/xml_files/isr_cities_1week_6hr_forecast.xml
```

**Method:** HTTP GET (no headers, no token, no login required — publicly accessible)

**Terms of use URL:** `https://ims.gov.il/en/termOfuse` — must be accepted before use.

**Update frequency:** Every hour

**File size:** ~21 MB (large — plan accordingly; stream or parse incrementally if needed)

## 4. Forecast Field Reference

| Field | Type | Unit | Notes |
|---|---|---|---|
| `ForecastTime` | datetime string | — | Format: `YYYY-MM-DD HH:MM:SS`; times are 03:00, 09:00, 15:00, 21:00 |
| `Temperature` | float | °C | Current temperature at time step |
| `RelativeHumidity` | integer | % | 0–100 |
| `WindSpeed` | integer | km/h | |
| `WindDirection` | integer | degrees | Meteorological convention (0/360 = N, 90 = E, 180 = S, 270 = W) |
| `DewPointTemp` | integer | °C | Can be negative |
| `HeatStress` | float | °C | Apparent temperature under heat conditions |
| `HeatStressLevel` | integer | index | 0 = no stress; higher = more heat stress |
| `FeelsLike` | float | °C | Combined apparent temperature |
| `WindChill` | integer | °C | Perceived coldness from wind |
| `Rain` | float | mm | Accumulated rain for the 6-hour period; 2 decimal places |
| `WeatherCode` | integer | — | See WeatherCode table below |
| `MinTemp` | integer | °C | Min temp during the 6-hour period |
| `MaxTemp` | integer | °C | Max temp during the 6-hour period |
| `UVIndex` | integer | — | UV index at time step (0 at night) |
| `UVIndexMax` | integer | — | Max UV index for the period |

## 7. Python Fetch Skeleton (for Claude Code)

```python
import requests
import xml.etree.ElementTree as ET
from datetime import datetime

FILE_URL = "https://ims.gov.il/sites/default/files/ims_data/xml_files/isr_cities_1week_6hr_forecast.xml"

def fetch_forecast():
    response = requests.get(FILE_URL, timeout=30)
    response.raise_for_status()
    return ET.fromstring(response.content)

def parse_forecast(root):
    issued = root.findtext("Identification/IssueDateTime")
    results = []

    for location in root.findall("Location"):
        meta = location.find("LocationMetaData")
        loc_id = meta.findtext("LocationId")
        name = meta.findtext("LocationNameEng")
        lat = float(meta.findtext("DisplayLat"))
        lon = float(meta.findtext("DisplayLon"))
        height = int(meta.findtext("DisplayHeight"))

        forecasts = []
        for fc in location.findall("LocationData/Forecast"):
            forecasts.append({
                "time": fc.findtext("ForecastTime"),       # "YYYY-MM-DD HH:MM:SS" (UTC+2)
                "temp_c": float(fc.findtext("Temperature")),
                "rh_pct": int(fc.findtext("RelativeHumidity")),
                "wind_kmh": int(fc.findtext("WindSpeed")),
                "wind_dir_deg": int(fc.findtext("WindDirection")),
                "dew_point_c": int(fc.findtext("DewPointTemp")),
                "heat_stress_c": float(fc.findtext("HeatStress")),
                "heat_stress_level": int(fc.findtext("HeatStressLevel")),
                "feels_like_c": float(fc.findtext("FeelsLike")),
                "wind_chill_c": int(fc.findtext("WindChill")),
                "rain_mm": float(fc.findtext("Rain")),
                "weather_code": int(fc.findtext("WeatherCode")),
                "min_temp_c": int(fc.findtext("MinTemp")),
                "max_temp_c": int(fc.findtext("MaxTemp")),
                "uv_index": int(fc.findtext("UVIndex")),
                "uv_index_max": int(fc.findtext("UVIndexMax")),
            })

        results.append({
            "id": int(loc_id),
            "name": name,
            "lat": lat,
            "lon": lon,
            "height_m": height,
            "forecasts": forecasts   # 35 entries, every 6h
        })

    return {"issued": issued, "locations": results}
```

## 8. Key Implementation Notes

- **No auth required** — plain HTTP GET, no API key, no session cookies.
- **File is ~21 MB** — do not load into memory repeatedly; cache locally and refresh hourly.
- **Datetime parsing** — use `datetime.strptime(t, "%Y-%m-%d %H:%M:%S")` and treat as `UTC+2` (Israel Standard Time / UTC+2 in winter, UTC+3 in summer as IDT). The file header's `IssueDateTime` uses a human-readable format (`Wed May 27 13:38:51 IDT 2026`).
- **35 time steps per location** at 6-hour intervals (03:00 / 09:00 / 15:00 / 21:00 local time). The window starts from the most recent past 03:00 slot and extends ~8 days.
- **ID gaps are normal** — the ID sequence is non-contiguous (e.g., IDs jump from 84 to 200, and 247/260/265/266/276 etc. are absent).
- **Negative `DisplayHeight`** — locations below sea level (e.g., Tiberias = -200m, En Gedi = -205m, Qumran = -330m).
- **`WeatherCode` is an integer** — IMS does not publish an official public English legend in the XML docs; values observed in current file: 1160, 1220, 1230, 1250, 1260, 1570, 1580. More codes appear in wet/winter seasons.
- **Terms of use PDF:** `https://ims.gov.il/sites/default/files/2026-03/Rights%20and%20terms%20of%20use%2007.01.26_0.pdf`
